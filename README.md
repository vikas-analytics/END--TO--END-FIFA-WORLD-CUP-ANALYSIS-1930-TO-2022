🏆 FIFA WORLD CUP DATA ANALYSIS 1930–2022 ⚽
End-to-End Data Analytics Project using Python, Pandas, Matplotlib, Seaborn & Power BI

Problem Statement:
FIFA World Cup data is distributed across multiple tournament, match and team-level records, making it difficult to identify historical performance trends, successful teams, scoring patterns and tournament-level insights. This project aims to clean, transform and analyze historical FIFA World Cup data from 1930–2022 and develop an interactive Power BI dashboard to provide meaningful insights into tournament and team performance.

📌 Project Overview

This project analyzes FIFA World Cup tournaments from 1930 to 2022, covering match results, teams, goals, tournament performance, standings, winners, runners-up, third-place teams and individual awards.

The project follows an end-to-end data analytics workflow:

Data Collection → Data Cleaning → Data Transformation → Feature Engineering → Exploratory Data Analysis → Visualization → Power BI Dashboard → Insights
