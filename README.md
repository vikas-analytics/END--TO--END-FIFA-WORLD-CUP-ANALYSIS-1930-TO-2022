🏆 FIFA WORLD CUP DATA ANALYSIS 1930–2022 ⚽

Problem Statement:

FIFA World Cup data is distributed across multiple tournament, match and team-level records, making it difficult to identify historical performance trends, successful teams, scoring patterns and tournament-level insights. This project aims to clean, transform and analyze historical FIFA World Cup data from 1930–2022 and develop an interactive Power BI dashboard to provide meaningful insights into tournament and team performance.
